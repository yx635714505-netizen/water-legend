# 后台出图与天正对象验证

用户要求任务在后台运行，不在工作桌面打开或激活 CAD。优先使用文件、CAD API 和隐藏的任务实例；新建后台辅助进程使用隐藏窗口。仅操作本任务创建且已确认身份的实例，不关闭或接管用户的其他 CAD 进程。

## 本机已验证的初始化顺序

环境为 AutoCAD 2020、T20 天正建筑 V8.0。此配置记录用于本机排查，其他机器应先定位实际版本和安装路径。

1. 创建隐藏的 AutoCAD 实例，先打开空白 `acadiso.dwt`，不要首先打开含天正原生对象的工作 DWG。
2. 在空白文档中加载匹配版本的天正模块：本机成功路径为 `C:/Tangent/TArchT20V8/sys23x64/` 下的 `tch_initstart.arx`、`tch_kernal.arx`、`tch_utility.arx`、`tch_pipebase.arx`、`tch_pipewire.arx`。已加载模块不重复加载；确认初始化完成后再打开工作副本。
3. 在该实例中执行原生对象操作、保存和打印。后台进程每次新建时都应处理初始化，不把前一实例已加载模块当作新实例也已就绪。
4. 先对少量原生文字和管线检查真实包围盒及打印可见性，再执行整套生成。不要仅凭模块名称、对象类型或成功保存来判定加载正确。

原生文字或管线缺失时，先核对模块加载顺序，保存重开后检查显示和打印。不得为修复显示而批量炸开图形或删除原生对象。

## 文字与对象操作

- 保持符号、管道、图例及其依赖的原生表达。同名块、文字样式及线型冲突需核对，不能仅凭名称采用目标图已有定义。
- 本机已使用原生命令移动、复制参照实体；其他方法应先验证变换后位置、关联对象、保存后重开及打印结果。不要照搬某个项目脚本中的句柄、移动量或绝对坐标。
- 个别说明文字的兼容处理遵循《出图版式与底图清理规则》，从原文字取得外观属性；默认黑体不作为回退方案。
- PowerShell 5.1 读取含中文路径的脚本时，本机采用 UTF-8 BOM；AutoCAD 2020 的旧式 LISP/SCR 文本按实际支持的编码写入并检查。避免脚本路径乱码造成无输出或操作错误目录。
- 通过 COM `SendCommand` 发送批次时明确使用单个命令终止符，不把 Windows CRLF、文件尾换行和追加回车叠加，避免空回车重复上一条修改命令。位置修订优先按绝对目标设置，并核对保存后的坐标，防止重试时重复平移。保存异常不等于修改已落盘；本机当前文档用 `QSAVE` 成功保存后再关闭、重开验证。
- 本机天正 `YCBZ` 对应 `TLEADER`，命令由 `tch_annotate.arx` 提供。后台绘制时先处理当前任务隐藏实例里的原生选项，再给出引点、基线起点和基线终点。单引点标注以两次回车分别结束追加引点和继续标注。保存后复核 `TCH_MULTILEADER` 的文字、引点和基线位置，并在全幅预览中检查相邻标注。

## 保存后验证

- 输出到独立的新项目/版本目录，保留输入建筑 DWG。移除工作副本中遗留的无关布局，保留本次实际图纸。
- 保存最终 DWG，关闭该工作文档，再在已正确初始化的实例中重新打开这个交付文件。用重新打开后的内容导出全部图纸预览。
- 核对说明长段、图例文字与符号、管线线型、建筑底图、签名区和图签字段。原生对象仍有类型但没有有效显示/包围盒时，继续排查，不能交付空白页面。
- 递归检查实际被引用的底图块，确认无无关建筑索引和多余平面说明；不要把未使用块定义中的文字当作图面残留。
- 检查完成后释放交付文件的占用并退出本任务创建的后台实例。不要把“仍在后台处理中”的文件作为已完成成品交付。
